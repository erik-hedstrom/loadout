# Vendor comparison test deliverables

All inputs are deliberately fictional samples, created because no real quotes were supplied.

- [Comparison and recommendation](comparison.md): side-by-side table, normalization, assumptions, factor winners, and questions for each vendor.
- [Cost breakdown](cost-breakdown.csv): spreadsheet-ready amounts in SEK. Zero shipping/setup/installation entries for Boreal mean included in its package. Cedar's empty installation entry means unknown. Year-three values are cumulative three-year costs.
- [Sample quotes](sample-quotes/): three source quotes with intentionally differing price bases, delivery commitments, warranties, and missing terms.
- [Validation record](validation.txt): arithmetic and file-link checks.

No external market prices, tax rules, or real vendor performance claims are used. The stated tax rate comes solely from the fictional quotes. There is no application code or repository integration in this document-only task.
